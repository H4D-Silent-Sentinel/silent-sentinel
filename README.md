# Silent Sentinel

Passive acoustic sensor network that keeps tracking small drones after they fly behind buildings and drop out of radar, camera and RF coverage (H4D, CENTCOM-4 "Drone Hide and Seek").

Six listening nodes (ESP32-S3 + 4× ICS-43434 mics + RFM95W LoRa) detect the rotor tone comb and send small reports over LoRa to a base laptop, which estimates position from loudness and tracks the drone with a Kalman filter. All equipment is receive-only on drone frequencies.

## Layout

| Path | What |
|---|---|
| `firmware/node/` | Listening node: dual-I2S capture, comb detector, LoRa reports. Pins in `config.h`. |
| `firmware/base_rx/` | Base receiver: forwards LoRa packets to the laptop over USB serial. |
| `cuas/detector.py` | Reference detector (numpy). The firmware mirrors it; tune here first. |
| `cuas/packet.py` | 24-byte LoRa packet format (matches `firmware/node/packet.h`). |
| `cuas/sim/` | Synthetic drone / noise / wind / generator audio. |
| `docs/wiring.html` | Node schematic and wiring tables (generated by `docs/make_wiring.py`). |

## Build the firmware

```sh
arduino-cli core install esp32:esp32
arduino-cli lib install LoRa
FQBN="esp32:esp32:esp32s3:PSRAM=opi,FlashSize=16M,PartitionScheme=app3M_fat9M_16MB"
arduino-cli compile --fqbn $FQBN firmware/node
arduino-cli upload  --fqbn $FQBN -p /dev/cu.usbserial-XXXX firmware/node
```

Use the DevKit's **COM** USB port. Serial console at 115200: `id <n>`, `debug 0|1`, `info`, `tx`.
