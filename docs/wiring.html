Silent Sentinel node wiring

REV A · 2026-11-17firmware/node/config.h

One listening node: ESP32-S3-DevKitC-1 N16R8, four ICS-43434 I2S microphones on two buses, and an RFM95W LoRa radio. Wires are drawn as net labels: every tag with the same name is one wire run. The base receiver is the same build with the microphones left off.

Schematic

3V3 power ground I2S bit clock I2S word select I2S data SPI radio control
3.3 V only. The microphones are 3.6 V max, and the RFM95W drives its SPI lines at whatever voltage is on VIN. Feed both from the DevKit's 3V3 pin. Nothing goes to 5V.

Microphones

Each bus carries two mics that share BCLK, WS and the data line. SEL picks the half of the frame a mic talks in: tied to GND it is the left channel, tied to 3V3 the right. Getting SEL wrong makes two mics talk over each other.

LoRa radio

The RFM95W uses SPI plus two control lines. G0 is the radio's interrupt line; RST lets the ESP32 reset it at boot.

Build order

  1. Solder headers on the 4 mic breakouts and the RFM95W. Solder a 78 mm straight wire to the RFM95W ANT pad.
  2. Seat the DevKit across the breadboard's center channel with its USB ports at the bottom, so header J1 matches the drawing. Run 3V3 and GND to the breadboard rails.
  3. Plug the DevKit into the laptop by its COM port and flash firmware/node. With nothing else wired, the serial console prints FAULT or WARN lines. That confirms the board and toolchain work.
  4. Wire the RFM95W. Reboot, type info: it should say lora=ok.
  5. Wire bus 0 (M0, M1). Type debug 1 and whistle or play a tone: the level column should jump.
  6. Wire bus 1 (M2, M3) the same way on IO7 / IO15 / IO16.
  7. Set the node number with id 1 … id 6. It is saved in flash.

Placement on the board

  • Spread the four mics in a square about 5 cm on a side, sound ports facing up and clear of wires. The ICS-43434 hears through a hole in its PCB, so don't cover it.
  • Keep mic wires short (under ~15 cm). Long I2S clock runs pick up noise.
  • Point the antenna straight up and keep it away from the mic wiring.
  • Outdoors, a foam windscreen over each mic matters more than anything in software.

Base receiver

A second DevKit with only the RFM95W wired, exactly as in the table. Flash firmware/base_rx and leave it plugged into the base laptop.
