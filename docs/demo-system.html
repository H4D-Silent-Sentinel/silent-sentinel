Silent Sentinel Demo System

One building, 4 listening nodes at the corners, 1 radar, 1 camera tracker, 1 RF receiver, fused at the C2. Pins and ports from firmware/node/config.h, radar/, roaree.

LoRa radios (RFM95W ×5)

One RFM95W per node (4) and one in the base receiver. Same part, same pins, same settings: 915 MHz, SF7, 500 kHz, sync 0x5E. The breakout has no antenna; each needs a 78 mm solid wire soldered to the ANT pad. Outline from Adafruit's board file, 10 px = 1 mm.

Base receiver breadboard, to scale

Same ESP32 and RFM95W positions as a node, no mics. Sits at the C2 table, powered and read over USB from the C2.

Node mounting at a building corner

Position comes from comparing loudness between nodes, so every node must be mounted identically: same height, same wall offset, same orientation. A node mounted differently reads louder or quieter and pulls the position estimate.
